## 2. Warstwa 1 — Stały Baner Kryzysowy

**Lokalizacja:** Subtelny pasek na dole każdego ekranu ćwiczenia — obecny, ale nie alarmujący. Jak wyjście ewakuacyjne w budynku.

### Treść baneru:
```
Potrzebujesz wsparcia? Telefon Zaufania: 116 123 · Centrum Wsparcia: 800 70 2222 · Więcej zasobów →
```

### Przycisk "Potrzebuję pomocy":
Dostępny z każdego ekranu. Po kliknięciu pokazuje pełną listę zasobów + tekst:

```
Jeśli czujesz, że potrzebujesz wsparcia — to ważna informacja.
Nie musisz radzić sobie sam/a.

Telefon Zaufania dla Dorosłych: 116 123 (całodobowo, anonimowo)
Centrum Wsparcia: 800 70 2222 (całodobowo, bezpłatnie)
Chat kryzysowy: 116111.pl

Jeśli jesteś w bezpośrednim niebezpieczeństwie, zadzwoń pod numer alarmowy: 112
```

## 4. Warstwa 3 — Content Warnings (Przed Trudnymi Ćwiczeniami)

### Ćwiczenia wymagające content warning:
- I-3: "Moment, Który Wszystko Zmienił" (difficulty 3/5)
- I-4: "Trudne Wspomnienie — Nowa Perspektywa" (difficulty 4/5)
- II-5: "Współczucie dla Siebie" (difficulty 4/5)
- III-2: "Najgorsza Możliwa Przyszłość" (difficulty 3/5)

### Szablon content warning:
```
To ćwiczenie może wywołać silne emocje — to normalne i nie oznacza,
że robisz coś źle.

Jeśli w jakimkolwiek momencie poczujesz, że to za dużo:
• Możesz przerwać i wrócić później
• Możesz pominąć to ćwiczenie
• Możesz skorzystać z ćwiczenia uziemiającego (5-4-3-2-1)

Twój tekst jest automatycznie zapisywany — nic nie zginie.
```

### Warianty dla konkretnych ćwiczeń:

**I-3 (Moment zwrotny):**
```
W tym ćwiczeniu wrócisz do momentu, który zmienił Twoje życie.
Nie musisz wybierać najbardziej bolesnego wspomnienia — każdy punkt zwrotny
się liczy. Jeśli w trakcie pisania poczujesz, że emocje są zbyt silne —
to sygnał, żeby zrobić przerwę, nie żeby się przełamywać.
```

**I-4 (Trudne wspomnienie):**
```
To ćwiczenie dotyczy bolesnego wspomnienia. Będziesz opisywać je
z dwóch perspektyw — swojej i współczującego obserwatora.
To NIE jest szukanie pozytywów w trudnych doświadczeniach.
To próba zobaczenia ich z innej odległości.

Jeśli czujesz, że nie jesteś gotowy/a — to w porządku.
Możesz wrócić do tego ćwiczenia za tydzień, za miesiąc, kiedykolwiek.
```

**II-5 (Współczucie dla siebie):**
```
Dla wielu osób to najtrudniejsze ćwiczenie w całym programie.
Jeśli pojawi się opór — to informacja, nie porażka.
Nasz wewnętrzny krytyk bywa bardzo głośny.
Daj sobie tyle czasu, ile potrzebujesz.
```

**III-2 (Najgorsza przyszłość):**
```
To ćwiczenie prosi Cię o wyobrażenie sobie przyszłości, w której nic się
nie zmienia. To może być nieprzyjemne — i taki jest zamysł. To nie jest
karanie siebie. To informacja — kontrast, który pomaga zobaczyć,
dlaczego zmiana jest ważna.

Jeśli wizja jest zbyt przytłaczająca — przerwij.
To ćwiczenie jest narzędziem, nie karą.
```

### Sekcja 2: Jak znaleźć psychoterapeutę
```
Szukanie terapeuty może być przytłaczające. Oto kilka kroków:

1. Psycholog czy psychiatra?
   - Psycholog/psychoterapeuta — terapia rozmową
   - Psychiatra — leki (jeśli potrzebne) + może prowadzić terapię
   - Często najlepiej: oboje jednocześnie

2. Gdzie szukać:
   - Twój lekarz pierwszego kontaktu (skierowanie do poradni zdrowia
     psychicznego na NFZ — bezpłatnie, ale kolejki)
   - Portale: psychoterapeuci.pl, psychologowie.pl, znanylekarz.pl
   - Platformy online: twojterapueta.pl, mindy.pl

3. Ile to kosztuje:
   - NFZ: bezpłatnie (kolejka: tygodnie-miesiące)
   - Prywatnie: 150-300 PLN za sesję (zwykle co tydzień lub co 2 tygodnie)
   - Niektórzy terapeuci oferują zniżki dla osób w trudnej sytuacji
   - Platformy online: często tańsze (80-150 PLN)

4. Jak wybrać:
   - Szukaj certyfikowanych psychoterapeutów (4-letnie szkolenie)
   - Pierwsza sesja to "poznanie" — nie musisz zostać
   - Jeśli nie czujesz się dobrze z terapeutą — szukaj dalej.
     To normalne, że nie każdy pasuje.
```
